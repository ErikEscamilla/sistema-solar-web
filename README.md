## Estructura del Proyecto
* `index.html`: Estructura principal.
* `css/`: Estilos base (`estilos.css`) y adaptativos (`queries.css`).
* `js/main.js`: Interactividad (Modales y validación).
* `assets/`: Imágenes originales de los planetas.
* `docs/`: Documentación de diseño.

## Funcionalidades
* Animación de bienvenida.
* Modales informativos para cada planeta.
* Validación de campos en el formulario de contacto.

## Cómo ejecutar
1. Descarga el repositorio o carpeta.

2. Abre `index.html` en tu navegador.
